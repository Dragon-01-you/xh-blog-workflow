# 施工小工单存放规则（`issue-tracker.md`：本地 Markdown 模式）

> **通俗解释**：`issue-tracker` 就是**「任务工单记事本」**。当 AI 把一个大网站拆成第 1 单、第 2 单、第 3 单时，这些工单文件往哪里放，就由这个文件规定。

## 存放规矩

- 每个大功能建一个专属文件夹：`.scratch/<功能名>/`
- **自动规划需求书（`spec.md`）** 存放在：`.scratch/<功能名>/spec.md`
- **拆分后的施工小工单（`issues`）** 一单一文件，存放在：`.scratch/<功能名>/issues/<编号>-<名称>.md`（从 `01` 开始编号，绝不把所有工单糊在同一个文件里）
- 每张工单开头写一行 `Status:`（当前状态，对应 `triage-labels.md` 里的 5 种状态）
- 讨论记录与修改历史写在工单最底部的 `## 备注与历史` 下方
