# 工单状态标签说明（`triage-labels.md`）

> **通俗解释**：`triage` 原意是医院急诊科的**「分诊贴标签」**。在项目里，就是给每一张施工工单贴上「现在处于什么状态」的标签，让你和 AI 一眼看出哪张单子可以直接干、哪张单子还在等你拍板。

| 技能内部英文代号 | 本项目使用的标签 | 大白话中文意思 |
|---|---|---|
| `needs-triage` | `needs-triage` | **【待评估】** 刚提出来的想法，还没决定怎么做 |
| `needs-info` | `needs-info` | **【缺信息】** 还有问题没问清楚，等主人（你）补充拍板 |
| `ready-for-agent` | `ready-for-agent` | **【AI 可直接干】** 要求已经写得明明白白，AI 可以全自动施工 |
| `ready-for-human` | `ready-for-human` | **【需人工处理】** 需要主人亲自操作（比如填真实银行卡或绑定域名） |
| `wontfix` | `wontfix` | **【决定不做】** 经过评估砍掉的需求，不浪费时间 |
