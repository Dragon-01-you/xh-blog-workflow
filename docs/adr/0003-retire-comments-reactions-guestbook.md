# 拍板备忘录 0003：砍掉评论与留言板，严守「公域免费引流 vs 私域付费交付」边界

> **对标原版**：`cali.so/docs/adr/0003-retire-comments-reactions-guestbook.md` + 芯火公私域内容转化法则
> **状态**：已拍板生效（Accepted）

---

## 一、我们要解决什么问题？（背景）
1. **为什么砍掉评论区、表情点赞与游客留言板（学 `cali.so`）**：
   - `cali.so` 运营后发现，公开评论和留言板会让站长把 90% 的精力浪费在清理垃圾广告、做防刷限流接口、接复杂的游客登录和数据库上；而且真正有价值的读者根本不是来看游客灌水的。
2. **为什么公域网站必须和私域/付费专栏拉开差距（芯火的核心商业逻辑）**：
   - **免费和付费必须有本质区别**：就像姜胡在小报童上的付费专栏，里面会给全套「四步填空卡（一键复制粘贴就能用）」、「内置 Skill 完整源码」和「逐句检查标准」——那是别人花钱买的核心交付物；
   - **如果我们在公域免费博客和作品页里，也把付费级的保姆式细节和全套底层配方毫无保留地免费贴出来**：第一，公域泛受众根本看不进长篇累牍的枯燥技术细节；第二，真正有需求的人白嫖完直接走了，再也没有理由付费或进入你的私域！
   - 所以，这个个人网站在公域的唯一定位就是**「价值放大器与私域引流漏斗」**。

## 二、我们的拍板决定
1. **果断砍掉**：不设公开评论区、不设游客留言板（`/guestbook`）、不设游客注册登录；
2. **公域内容与作品页只做「价值证明与认知破局」**：
   - **公域免费展示什么**：展示「真实痛点是什么 → 我做出了什么惊艳结果（配真实截图/数据） → 核心认知破局点（偶尔放 1~2 篇精品心得或轻量尝鲜版）」，让读者心服口服地觉得“芯火真有东西、真能帮我解决问题”；
   - **私域/付费保留什么**：把保姆级填空模板、完整内置 Skill 包、深水区实操步骤留在私域/付费专栏；
3. **内置小报童同款「上下篇导航 + 闭门课/私域引流横幅卡」**：
   - 在每篇文章底部和作品页底部，标配「上一篇 / 下一篇」跳转卡，以及一张带芯火红点缀的私域转化横幅卡，承接公域流量进入私域。
