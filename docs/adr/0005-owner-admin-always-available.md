# 拍板备忘录 0005：保留站长专属可视化后台（`/admin`），未配外部真密钥时默认安全只读

> **对标原版**：`cali.so/docs/adr/0008-owner-admin-is-always-available.md`
> **状态**：已拍板生效（Accepted）

---

## 一、我们要解决什么问题？（背景）
虽然我们在备忘录 0001 里拍板了“博客文章直接用 `.mdx` 文件写在项目文件夹里”，但一个成熟的个人品牌主站除了写文章，站长平时还需要：
1. 一眼看清目前全站发了多少篇文章、多少字、多少个代表作、各自动推广接口（`SEO`/`RSS`/`OG`/`llms.txt`）是否健康；
2. 管理日常精选照片墙（`/admin/photos`）和一对一咨询预约状态（`/admin/ama`）。

如果完全没有可视化后台，站长想看一眼全站资产状态都得去翻代码文件夹，不够直观。

## 二、我们的拍板决定
1. **保留站长专属可视化后台（`/admin`）**：提供干净的中文站长控制台，集中展示全站文章/作品资产总览、自动推广四件套状态检查面板、以及照片/咨询管理入口；
2. **防搜索引擎偷看**：在 `/robots.txt` 和页面安全头里强制标记 `/admin` 为 `noindex, nofollow`（严禁百度/Google 收录后台页面）；
3. **默认安全关闭外部写操作（Fail-Closed）**：在本地免密码练习场模式下，后台可以完整浏览和巡检全站资产，但涉及外部云图床或真实日历扣款的危险写操作会自动处于“安全锁定保护”状态，绝不报错崩溃。
