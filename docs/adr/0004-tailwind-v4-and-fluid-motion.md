# 拍板备忘录 0004：UI 布局复用 cali.so 现成骨架，视觉采用「Mono 极简黑白灰 + 唯一芯火红」热插拔皮肤

> **对标原版**：`cali.so/docs/adr/0006-shadcn-tailwind-v4-fluid-registry.md` + `mono-editorial-design-skill`（Mono 黑白编辑式设计原则）
> **状态**：已拍板生效（Accepted）

## 一、我们要解决什么问题？（背景）
1. **UI 界面需要我们自己从头画设计图或每页去 AI 出图吗？**
   - **不需要！** 网站页面排版（UI 布局）直接 **1:1 复用 `cali.so` 已经验证成熟的现成页面骨架**（首页抬头、文章列表、带顶部铭牌与左侧迷你标尺的正文页、作品网格、底部胶囊导航栏），我们在它的现成基础上做微调（如加上文末的小报童式「上下篇 + 私域引流横幅」）。
   - 同时，按照 `mono-editorial-design-skill` 的铁律：**“大字即骨架、真实素材优先、靠字号/字重/留白做层级”**——全站 95% 的视觉直接由代码排版生成，不需要 AI 画假背景图；仅有的头像直接用知识库现成的 `芯火logo-螺旋.png`，作品配图直接用知识库现成的真实截图（转灰度或原图）。
2. **配色方案怎么定？**
   - 放弃繁琐的多彩配色，严格采用 `mono-editorial-design-skill` 的 **「Mono 极简黑白灰 + 唯一芯火红点缀」**，并通过 CSS 变量做成可热插拔皮肤。

## 二、我们的拍板决定
1. **默认主皮肤：「芯火 Mono 极简黑白灰 + 芯火红（`mono-xinhuo`）」**：
   - **浅色模式（纸白系）**：主背景 `#F6F5F2`、次级表面 `#F4F4F2`、细边框 `#D9D6D0`、大标题纯黑 `#111111`、正文深灰 `#3F3F3F`、次级说明 `#5A5A5A`、弱信息 `#8A8A8A`；
   - **深色模式（墨黑系）**：主背景 `#0C0C0C`、卡片表面 `#161616`、细边框 `#2E2E2E`、大标题暖白 `#F7F6F3`、正文亮灰 `#D8D6D1`、次级说明 `#B6B4AF`、弱信息 `#8C8A85`；
   - **唯一装饰点缀色（芯火红 `--signal`）**：全站绝不出现蓝、紫、绿等杂色；仅在底部胶囊导航栏的 `5px` 指示印章、左侧章节标尺当前刻度、以及文末私域引流按钮处使用一抹**「芯火红」**（`#D93829` / 深红 `#9E2A2B`）。
2. **反 AI 味动效纪律（对齐 `mono-editorial-design-skill` 第 4 条不变量）**：
   - 严禁无限循环动效、严禁 `transition: all`、严禁花哨弹性过冲、严禁常驻大阴影与玻璃拟态；
   - 仅保留 `160ms` 短促克制的状态染色过渡与一次性入场呈现。
