# 00 · 评分 Rubric（唯一事实源）

> 任何评分调整只改这里 + `scripts/audit.py`，其它文档不得另立标准。

## 1. 维度与权重（合计 100）

| 维度 | 权重 | 包含 |
|---|---:|---|
| 门面 | 18 | README 存在、H1、Hero、徽章、演示、目录、英文版、协议、图片可解析 |
| SEO | 18 | 描述、关键词、项目链接、CITATION、命名一致性、一句话定位、H1 含名、社交预览 |
| **GEO** | **22** | llms.txt、llms 结构、问答结构、事实表、对比章节、机读数据、FAQ、实体一致性 |
| 内容深度 | 16 | 快速开始、代码块、环境表、架构、路线图、CHANGELOG、真实案例 |
| 社区 | 10 | CONTRIBUTING / SECURITY / COC / Issue 模板 / PR 模板 / 贡献入口 |
| 工程 | 10 | CI、测试、依赖声明、版本单一来源、打包清单 |
| 安全 | 6 | 密钥扫描、.gitignore 泛化、大文件 |

**为什么 GEO 权重最高**：SEO 争的是"第几页"，GEO 争的是"有没有被写进答案"。前者是流量，后者是定义权。

## 2. 单检查判定

| 状态 | 计分 | 判定标准 |
|---|---|---|
| `pass` | 全额 | 证据充分（文件存在 / 正则命中 / API 200） |
| `warn` | 50% | 存在但质量不足（徽章 2 枚、描述 210 字符、目录 3 项） |
| `fail` | 0 | 缺失或明确错误 |
| `skip` | 不计入分母 | 无 pyproject / 无 token / 结构不适用 |

分数 = Σ(权重 × 状态系数) / Σ(生效权重)，再折算到该维度满分。

## 3. 等级锚点

| 分数 | 等级 | 含义 | 典型仓库 |
|---:|---|---|---|
| 90–100 | **A** | 顶流水准，放进 awesome-list 不违和 | uv、whisper、shadcn/ui |
| 80–89 | **B** | 可发布，有明显亮点，仍有 3–5 个缺口 | 成熟中小项目 |
| 65–79 | **C** | 能看，但首屏留不住人 | 多数个人项目 |
| 45–64 | **D** | 功能可能有，门面没做 | 刚开源的工具 |
| <45 | **E** | 几乎只有代码 | 内部脚本仓 |

实测校准：xh-forensics 94（A）、LLMmap 58（D）。**分数必须能区分仓库，不能人人 80+。**

## 4. 人工加分项（可选，最多 +5，单列不并入 100）

这些是顶流仓库的「非必需但显著加分」特征：

| 特征 | 加分 | 证据 |
|---|---:|---|
| Hero 支持深浅色 `<picture>` | +1 | 两套 srcset |
| 有 benchmark 图 + 指向 BENCHMARKS 的链接 | +2 | 图 + 带数字的 claim |
| 平台安装矩阵（mac/linux/win 分行） | +1 | 独立代码块 |
| 顶部链接行（Blog / Paper / Model card / Colab） | +1 | 首屏 4 个外链 |
| 有独立文档站且 README 只做路由 | +1 | 文档域名 |
| 社交证明（用户/集成/媒体报道） | +1 | 第三方来源，非自夸 |

超过 5 分只记 5 分，避免用装饰堆分。

## 5. 证据格式（强制）

```
Finding    一句话说问题
Evidence   具体元素/指标/片段 + 来源（文件:行、API 字段、截图）
Impact     为什么影响获客/转化/被引用
Fix        可执行的一步（改哪个文件、改成什么）
Confidence Confirmed | Likely | Hypothesis
```

反例：「README 不够吸引人」——没有 Evidence、没有 Fix、无法验证。

## 6. 常见误判

| 误判 | 纠正 |
|---|---|
| 徽章越多越好 | 超过 8 枚，首屏可读性下降；3–5 枚关键徽章更强 |
| 目录越长越好 | TOC 超过 20 项说明内容没分层，应拆文档站 |
| 英文版逐句直译 | 结构同构、表达重写；直译读起来像机翻 |
| 有图就加分 | 装饰图不加分；能解释结构的图才加分 |
| 描述写满 160 字符 | 前 80 字符必须独立成句，后面可被截断 |
| 演示 GIF 越大越清晰 | >1 MB 加载慢，反而降低完成率 |
| 把"没测到"当"不合格" | 环境限制标 `Hypothesis`，不计 fail |

## 7. 复算与回归

- 每次调整权重，跑 `audit.py` 对**至少 3 个仓库**（1 个自己的 + 2 个外部）验证区分度
- 分数变化 >5 分必须能解释到具体检查项
- 不允许为了"好看"手改 JSON 分数
