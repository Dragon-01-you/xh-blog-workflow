# 30 秒宣传片分镜模板

> 交付物：16:9、30.000 s、默认静音可读、无口播（可选后配音）。
> 一句话目标：观众只记住一句 —— **「{核心结论}」**。

## 一条片子只讲一件事

| 项 | 填写 |
|---|---|
| 观众 | {谁} |
| 场合 | README 首屏 / X / 视频号（默认静音、自动播放） |
| 看完要记住的一句 | {一句话} |
| 主形状 | Evidence（证明为什么成立）/ Workflow（看它怎么跑）/ Showcase（罗列能力，慎用） |

## 制作约定

- **像素里的字**（片尾地址、产品名、数字）改动必须重渲染，不能只改 README
- 每屏只保留一个焦点；字号对比 ≥ 2.5 倍
- 全片禁止纯黑纯白：用 `#111` / `#f4f2ee` 这类近黑近白
- 音轨：-14 LUFS、峰值 ≤ -1.5 dB、恰好 30.000 s（`-t 30.000` 硬截断）
- 交付三件套：`promo-30s.mp4`（<10 MB）、`poster.jpg`（关键帧）、`teaser.gif`（<2 MB）

## 验收（逐条打勾）

- [ ] `ffprobe` 视频/音频/容器时长均为 30.000
- [ ] 抽帧核对：片尾地址、卡片数字、产品名全部正确
- [ ] `om qa`（或等价脚本）：无爆音、硬切 ≤ 3、平均镜头 ≥ 6 s
- [ ] 静音看一遍，仍能懂
- [ ] 手机宽度（390px）看一遍，小字仍可读
